# Decision index

Settled 2026-11-05 after a prior-art study and two independent design
reviews. [`prior-art.md`](./prior-art.md) holds the survey, the rejected
alternatives and the evidence behind most rows.

Reversing or narrowing a row needs an ADR in `docs/adr/` that names the row it
supersedes. Mark the row `superseded` and link the ADR; never rewrite a row in
place.

## Sectioning and pagination

| #   | Decision                                                                                                                                                                                                                          | Status   |
| --- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------- |
| 13  | Sectioning runs on the Markdown AST; no regex splitting                                                                                                                                                                           | accepted |
| 14  | Slide level picked by Pandoc's rule: the highest heading level followed directly by content. A lone leading H1 is the document title (the cover) and is skipped, so a README-shaped doc gets `##` slides                          | accepted |
| 15  | A heading above the slide level gets a title slide only when it has its own content; breadcrumbs appear on every slide below it                                                                                                   | accepted |
| 16  | A thematic break forces a slide                                                                                                                                                                                                   | accepted |
| 17  | An overflowing slide with lower headings splits one level down, keeping the parent in the breadcrumb                                                                                                                              | accepted |
| 18  | Full semantic pagination ships in v1: paragraph, list-item and table-row boundaries, repeated table headers, "· continued" titles                                                                                                 | accepted |
| 19  | Code blocks, diagrams and images are atomic; one taller than an empty slide gets a diagnostic; no global shrink                                                                                                                   | accepted |
| 20  | Level override in the UI and URL: `auto`, H1, H2, H3 or a list                                                                                                                                                                    | accepted |
| 21  | Slides are addressed as `<section-id>/<n>`, never by absolute index                                                                                                                                                               | accepted |
| 22  | Measurement order: fonts ready, `mermaid.run()`, image decode, one animation frame; measure the slide and each Mermaid host; `ResizeObserver` re-checks; binary search over whole blocks in a hidden slide-sized box; cached SVGs | accepted |

## Workspace, editors and agents (added 2026-11-05)

| #   | Decision                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | Status   |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------- |
| 53  | Monaco is an optional second editor behind the decision 4 props contract: lazy-loaded, chosen in the More menu, remembered in `localStorage`, desktop only (touch devices keep CodeMirror), workers self-hosted from the build                                                                                                                                                                                                                                                                               | accepted |
| 54  | Canvas mode: a Mermaid diagram opens as an editable Excalidraw sketch through `@excalidraw/mermaid-to-excalidraw`, lazy-loaded; sketches stay in the browser (IndexedDB, keyed by document and diagram) and export as `.excalidraw`, PNG or SVG; nothing is written back into the Markdown (rule 1)                                                                                                                                                                                                          | accepted |
| 55  | Comments anchor to a heading slug or a Mermaid node id; they live in the browser (IndexedDB, keyed by document identity), travel inside the share link, and export and import as a `<name>.comments.json` sidecar; no server-side storage                                                                                                                                                                                                                                                                    | accepted |
| 56  | Turkish is the second UI locale through Paraglide (decision 30), with a language switch; layout uses CSS logical properties so an RTL locale needs no rewrite                                                                                                                                                                                                                                                                                                                                                | accepted |
| 57  | Workspace: files and folders in the origin private file system (OPFS), a file tree beside the outline, New file, New folder, New project from a template, rename and delete, zip import and export (fflate); with an empty workspace the app behaves as the single-document viewer it is today                                                                                                                                                                                                               | accepted |
| 58  | Local folder through the File System Access API (`showDirectoryPicker`, Chromium only; other browsers keep the OPFS workspace); the handle is kept in IndexedDB; a file changed on disk reloads (`FileSystemObserver` where available, polling otherwise); edits are written back only on an explicit save, and a disk change over unsaved edits asks which to keep                                                                                                                                          | accepted |
| 59  | Agents edit through a local MCP server (`docwalk-mcp`, stdio, Node) that is given a room's join link: it encrypts with the room key like a phone remote, so end-to-end encryption holds and the Worker never sees the document. Tools: `get_document`, `write_document`, `list_slides`, `goto_slide`. The presenter must switch on "Allow agent edits" in the room before a write is applied. Chat apps that only take remote MCP servers are not supported, because a Worker-side server would need the key | accepted |
| 60  | Comment details (refines 55). Identity: the `?src=` URL (tokens stripped), `?repo=` path or file name when there is one, so comments outlive upstream edits; else a SHA-256 of the text as opened. Edits keep identity; a `draft` alias finds the draft's comments after a reload. Node anchor: heading slug + diagram number + source node id from the SVG. Links: `#doc=…&c=…` or `#c=…`, dropped with a warning past the cap, imported once. Imports merge by id, last edit wins; no tombstones           | accepted |
